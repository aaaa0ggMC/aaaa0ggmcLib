# 现代化表格渲染引擎 (alib6.table)

`alib6.table` 是一个功能强大的终端表格与排版引擎。全面支持 Unicode/ASCII 全套边框预设、多行单元格换行、自动计算 CJK/Emoji 终端字符宽度对齐，以及任意深度的子表格嵌套渲染。

---

## 1. 核心功能亮点

- **丰富的边框预设**：`unicode_rounded()`（圆角）、`unicode_box()`（方角）、`ascii_box()`、`markdown()`、`modern_dot()` 等。
- **完美的宽度计算**：准确识别中日韩（CJK）全角字符、宽字符及 Emoji，避免由于字符宽度不匹配导致的边框错位变形。
- **多行单元格自动对齐**：单元格内包含 `\n` 时，自动计算最高行并按配置（Top, Center, Bottom）垂直对齐。
- **无限层级表格嵌套**：子表格可直接作为父表格的一个单元格嵌入渲染。

---

## 2. 代码示例

```cpp
import alib6;
#include <print>

using namespace alib6;

int main() {
    // 1. 创建圆角 Unicode 表格
    Table tbl(TableConfig::unicode_rounded());
    tbl[0][0] = "模块名";
    tbl[0][1] = "功能特性";
    tbl[0][2] = "健康度";

    tbl[1][0] = "alib6.core";
    tbl[1][1] = "PMR 内存 / 反射 / 管道解析";
    tbl[1][2] = "100% ✓";

    tbl[2][0] = "alib6.table";
    tbl[2][1] = "多行排版\nCJK宽度校准\n嵌套表格支持";
    tbl[2][2] = "100% 🚀";

    // 2. 创建嵌套子表格
    Table sub_tbl(TableConfig::unicode_box());
    sub_tbl[0][0] = "指标";
    sub_tbl[0][1] = "数值";
    sub_tbl[1][0] = "延迟";
    sub_tbl[1][1] = "0.2ms";
    sub_tbl[2][0] = "吞吐";
    sub_tbl[2][1] = "10M/s";

    tbl[3][0] = "子系统详情";
    tbl[3][1] = sub_tbl;
    tbl[3][2] = "运行中 🟢";

    // 3. 打印渲染结果
    std::println("{}", tbl);
    return 0;
}
```
